# Responsive

## 断点

| 名称 | 范围 |
|------|------|
| Mobile | < 768px |
| Tablet | 768px – 1024px |
| Desktop | > 1024px |

## 全局

- **顶部导航**：桌面水平排列，滚动隐藏 / 上滚出现；移动端汉堡菜单，全屏展开。
- **间距**：移动端间距大致减半（参考 `spacing-grid.md`）。
- **字号**：使用 `clamp()` 做流体字号，小屏自动缩小。

## 首页

| 断点 | 布局 |
|------|------|
| 桌面 | 首屏上下布局，三张项目卡片一行三列 |
| 平板 | 保持一行三列 |
| 移动 | 纵向堆叠，卡片单列 |

## 项目总览

| 断点 | 布局 |
|------|------|
| 桌面 | 左侧固定筛选面板 + 右侧三列网格 |
| 平板 | 保持三列网格，筛选面板折叠 |
| 移动 | 顶部折叠筛选 + 单列卡片网格 |

## 项目详情

| 断点 | 布局 |
|------|------|
| 桌面 | 右侧固定锚点导航 + 线性滚动内容 |
| 移动 | 顶部折叠锚点面板 + 纵向堆叠内容 |

## 个人资料

| 断点 | 布局 |
|------|------|
| 桌面 | 模块卡片式网格 |
| 移动 | 全部单列堆叠 |

## 移动端项目卡片

- 精简信息：只显示封面 / 标题 / 标签。
- 隐藏时间字段（`hidden sm:block`）。
- 封面保持 16:9 比例。
