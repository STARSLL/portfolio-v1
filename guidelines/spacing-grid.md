# Spacing & Grid

## 基础单位

**8px**。所有间距必须是 8 的倍数（或半步 4px）。

## 间距 Token

| Token | 值 |
|-------|----|
| `space-1` | 4px |
| `space-2` | 8px |
| `space-3` | 16px |
| `space-4` | 24px |
| `space-5` | 32px |
| `space-6` | 48px |
| `space-7` | 64px |
| `space-8` | 80px |
| `space-9` | 96px |
| `space-10` | 128px |

## 宽松留白应用

| 位置 | 桌面 | 移动 |
|------|------|------|
| 首屏上下内边距 | 80px | 40px |
| 区块之间 | 100–120px | 60px |
| 页面底部 | 160px | 80px |
| 模块之间（同区块内） | 40–60px | 30px |

移动端间距大致减半。

## 栅格

### 桌面端（> 1024px）

| 属性 | 值 |
|------|----|
| 列数 | 12 |
| 最大内容宽度 | 1280px |
| 两侧留白（gutter） | 40px |
| 列间距 | 20px |

### 移动端（< 768px）

| 属性 | 值 |
|------|----|
| 列数 | 4 |
| 两侧留白 | 20px |
| 列间距 | 10px |

## 规则

- 禁止在 8px 栅格之外使用随意间距（如 13px、22px）。
- 大面积留白是设计语言的一部分，不要填满每一块空间。
- 内容最大宽度 1280px，居中对齐，两侧 40px 安全区。
