# Motion

## 基调

平滑滚动 + 元素渐入 + 轻微位移 + 锚点平滑跳转。
首页、项目总览、个人资料三页统一动效规则。
项目详情页：统一基础 + 每个项目一个专属首屏/关键动效。
后续版本：逐步让每个项目完全独立动效体系。

## 时长

| 场景 | 时长 |
|------|------|
| 微交互（hover、点击反馈） | 150–200ms |
| 滚动渐入 | 400–600ms |
| 锚点跳转 | 600–800ms |
| 专属首屏动效 | 800–1200ms |

## 缓动

| 场景 | 缓动函数 |
|------|----------|
| 微交互 | `cubic-bezier(0.25, 0.1, 0.25, 1)` |
| 滚动渐入 | `cubic-bezier(0.16, 1, 0.3, 1)` |
| 锚点跳转 | `cubic-bezier(0.25, 0.1, 0.25, 1)` |

## 元素渐入

- **初始状态**：`opacity: 0`，`translateY(20px)`（移动端 12px）
- **进入状态**：`opacity: 1`，`translateY(0)`
- **触发条件**：Intersection Observer，元素进入视口 20% 时触发
- **双向**：离开视口时回退至初始状态（`once: false`），支持上下滚动双向动效

## 粒子系统

- 粒子缓慢漂移，home 位置做平滑随机游走，形成大弧度轨迹。
- 鼠标 160px 内：粒子向鼠标聚集（弱引力）。
- 鼠标离开：弹簧力驱动粒子平滑回归 home 位置。
- 每 200 帧随机给一粒子施加冲量，产生彗星划过效果。
- 大型光晕粒子：径向渐变绘制，有软发光效果。

## 移动端降级

- 粒子数量减半。
- 帧率可降至 30fps（使用 `requestAnimationFrame` 跳帧）。
- 部分复杂元素静态化（如旋转选区框动效）。

## 禁止

- 无目的的闪烁、抖动、弹跳。
- 超过 1200ms 的单次动效（首屏专属除外）。
- 同一时间超过 3 个并行动效（视觉噪声）。
